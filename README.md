# Tor Project - Legacy Repository

This repository is **deprecated** and no longer actively maintained. The core Tor project has moved to a new GitLab repository.

Please find the current source code, issue tracker, and development activity at:

[https://gitlab.torproject.org/tpo/core/tor](https://gitlab.torproject.org/tpo/core/tor)

## About Tor

Tor protects your privacy on the internet by hiding the connection between your Internet address and the services you use. We believe Tor is reasonably secure, but please ensure you read the instructions and configure it properly.
